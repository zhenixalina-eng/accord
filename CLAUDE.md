# Укулельная тетрадь

Песенник с аккордами: тексты песен распознаются с фото тетради и скринов, собираются в
сайт, по которому играют на укулеле или гитаре.

## Как устроено

- `songs/*.txt` — источник правды. Одна песня — один файл: заголовок `title/artist/key`,
  пустая строка, дальше текст с аккордами в квадратных скобках прямо перед нужной буквой:
  `Гран[Am]ицы кл[F]юч`. Позиция аккорда = число символов текста до скобки, поэтому
  аккорд встаёт ровно над этой буквой.
- Если для одной песни есть **несколько вариантов аккордов** (из разных источников, проще
  или сложнее, в другой тональности), каждый начинается строкой `--- Название варианта`,
  под которой может стоять свой `key:`. Название короткое — оно становится кнопкой на
  странице: «Из тетради», «Проще, без баррэ», «Со скрина». Без таких строк песня считается
  одним вариантом, и переключатель не показывается.

  ```
  title: Весна
  artist: Ночные Снайперы
  key: Dm

  --- Из тетради
  key: Dm

  [Dm]процент сумасшедших...

  --- Проще, без баррэ
  key: Am

  [Am]процент сумасшедших...
  ```

- `songs/index.json` — список файлов песен в порядке добавления. Новая песня должна быть
  дописана сюда, иначе её не будет на сайте.
- `index.html` в корне — сама страница. Читает `songs/` напрямую, поэтому на сайте песня
  появляется сразу после публикации файлов, без сборки.
- `build.mjs` и `site/app.html` — только для запасной публикации в Artifact: сборка вшивает
  тексты песен внутрь страницы. Для основного сайта это не нужно.

## После добавления песни

**В Artifact публиковать не нужно** — при открытии по ссылке артефакт отдаёт ту версию,
которая была закреплена при первом открытии, поэтому новые публикации до пользователя
не доходят. Это тупиковый путь, не трать на него шаги.

Просто добавь песню в `songs/` и допиши её в `songs/index.json`, а в ответе пользователю
назови её («добавил „Всё залить“ — Пионерлагерь Пыльная Радуга»).

Идёт переезд на GitHub Pages. Как только у репозитория появится remote (`git remote -v`
что-то показывает), порядок станет такой — и тогда сайт обновляется сам, без сборки:

```
git add songs/ && git commit -m "Добавлена песня: <название>" && git push
```

## Аппликатуры аккордов

Схемы аккордов лежат в `SHAPES` в `index.html` — отдельно для укулеле (4 струны,
строй GCEA) и гитары (6 струн, EADGBE): номера ладов, `0` — открытая струна, `-1` — глушится.
Если в новой песне встретился аккорд, которого там нет, карточка покажет «нет схемы» —
значит, надо дописать аппликатуру для обоих инструментов.

Открытые струны на схеме не отмечаются — только точки прижатия, баррэ и крестики
заглушенных струн.

## Параллельная работа

Над проектом работают несколько сессий одновременно: одна занимается расстановкой аккордов
в `songs/*.txt`, другая — самой страницей. Поэтому перед правкой `index.html` перечитывай
файл: он мог измениться.
